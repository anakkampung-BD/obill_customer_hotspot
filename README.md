# obill_customer_hotspot

Aplikasi Android untuk membeli akses internet hotspot **onesky.id** lewat ponsel.

## Kegunaan

Aplikasi ini dipakai pelanggan yang terhubung ke jaringan hotspot onesky.id dan ingin membeli paket internet tanpa harus membuka halaman web.

Alur singkat:

1. Masuk dengan nomor WhatsApp, lalu masukkan kode OTP yang dikirim.
2. Pilih lokasi/router, paket, dan metode pembayaran.
3. Bayar lewat QRIS — tampilkan kode QR di layar dan selesaikan pembayaran.
4. Setelah lunas, voucher ditampilkan untuk dipakai mengakses internet.
5. Transaksi yang belum selesai bisa dibatalkan dari aplikasi.

Fitur lain:

- Tema terang dan gelap
- Pemberitahuan jika ada transaksi yang masih berjalan
- Pembaruan aplikasi otomatis saat versi baru tersedia
